# VOXGUARD

**AI-Powered Voice Deepfake Detection System**

## About
VOXGUARD is a prototype designed to analyse uploaded audio and identify whether it is likely to be genuine speech or a potential AI-generated voice spoof.

## Proposed Workflow
1. Upload an audio file.
2. Preprocess the audio.
3. Analyse it using the AASIST deepfake detection model.
4. Display the prediction through a user interface.

## Technology Stack
- Python
- PyTorch
- ONNX Runtime
- Librosa
- SoundFile
- FastAPI (planned)
- HTML, CSS and JavaScript (planned)
